# Yong Zhen Kang — Portfolio

## View locally

Open `index.html` in a web browser. The page is self-contained and works without a build step or external libraries. The CV download link expects `Yong_Zhen_Kang_CV.pdf` in the same folder.

## Publish

Upload the contents of this folder to a static web host such as GitHub Pages, Netlify, or Cloudflare Pages. Set `index.html` as the entry page. Before publishing, confirm that the phone number, email, LinkedIn URL, role dates, and CV are current.

## Customize

Edit the text and design tokens in the `<style>` block in `index.html`. Replace the abstract monogram panel with a professional photo or project image if you want a more personal visual. Add more case studies when you have additional project details, repositories, or screenshots to share.


The Activities section currently uses clearly marked photo placeholders. Replace each placeholder in index.html with a supplied image when ready.


The Blood Donation App case study groups its screenshots by feature. The original full-length mobile screenshots are displayed without cropping or blur. Eligibility and push-notification screenshots are placeholders ready to replace. Keep the project-assets and activity-images folders beside index.html when publishing.
